The corrected isolated FE dedendum response is 0.178987 µm RMS, compared with 0.196589 µm analytically. The earlier ninefold contrast mixed addendum and dedendum modifications and is superseded. Restricted fits do not identify dedendum presence or geometry in the tested cross-operator data. Version 12 adds waveform and phase-mask controls, a fixed-body pressure-interface study, physically modified contours with reassembled stiffness, and verification of 42 bibliographic entries. The article makes conditional observability claims, not validated physical profile recovery.

The package contains scripts, numerical records, 20 supplementary tables, verification reports and checksums. Its README explains execution and evidence boundaries. Forty unit tests pass; all 1800 archived statistical fits were audited but not all were refitted.

[The historical manuscript-v10 tag](https://github.com/romusan/gears-inversion-reproducibility/tree/manuscript-v10) remains unchanged. Its historical claims must be read with the corrections in version 12. No DOI is assigned to the new package.
